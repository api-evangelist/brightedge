# BrightEdge

> BrightEdge is an enterprise SEO and content performance platform (founded 2007, Silicon Valley) whose products include the DataCube data repository, ContentIQ site auditing, Autopilot, Copilot, the DataMind AI engine, and AI Catalyst. The BrightEdge Platform API (v5.0) is a REST API at api.brightedge.com exposing accounts, keywords, keyword groups, competitors, domains, pages, backlinks, the DataCube dataset, recommendations, People-Also-Ask, SERP features, Core Web Vitals, bulk export, and user/organization management.

## APIs
- [BrightEdge Platform API portal](https://api.brightedge.com/portal): Swagger UI for the v5.0 REST API
- [OpenAPI 3.1 spec](https://api.brightedge.com/portal/openapi.json): machine-readable definition (248 operations)
